# Nekoma's Fixed for NeoForge 1.21.1

An unofficial NeoForge 1.21.1 port of [Nekoma's Fixed](https://github.com/GreenJAB/nekomas-fixed) by Green_Jab and team, the mod
built from the ideas in [Nekoma](https://www.youtube.com/@Nekoma7)'s videos. MIT licensed, like the original. All credit for the mod's
ideas, code and art goes to its authors, listed in the mod's own credits screen. Please report bugs of this port here, not upstream.

- **Needs:** Minecraft 1.21.1 and NeoForge 21.1.200 or newer, on both client and server. No other mods are required.
- **Works with:** [JEI](https://modrinth.com/mod/jei) (optional).
- **Options:** the pause menu's *Mod Options* button, the Mods list, or the mod's tab when creating a world. They are saved per world in
  `nekomasfixed.json` in the world folder.
- **Languages:** English and Brazilian Portuguese. The Portuguese is a full translation using Minecraft's own Brazilian wording.

It is based on upstream's 1.21.1 branch and upstream `main` (0.5.5). See [PORTING.md](PORTING.md) for what is left out because 1.21.1 lacks
the vanilla content it builds on.
